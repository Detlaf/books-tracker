# Tracker for read books

This document describes requirements for a book tracking app.

## Features

1. Books search: by title, author, by ISBN code (could be added manually or scanned with a camera)
2. Ability to add books to backlog (to read, reading, read)
3. Reporting tab which shows statistics on number of books read (with breakdowns by year, language, showing most popular authors)
4. Book rating feature: can assign ratings 1-5 to read books
5. Books collections: can group books in custom collections

## Overview

The app should have a backend, a web component (front-end) and a mobile version for Android.
